## sherpa-onnx

<https://github.com/k2-fsa/sherpa-onnx> — Apache License 2.0

Runtime for on-device ASR (SenseVoice) and voice activity detection.

The application does not use the native library in the AAR the sherpa-onnx
project publishes. That library links a text-to-speech engine (espeak-ng,
GPL-3.0-or-later). The native library used here is built from the same
upstream release with text-to-speech switched off, by
`tools/build-sherpa-onnx-no-tts.sh`; it contains no espeak-ng code.

Everything else in the rebuilt AAR is taken over unchanged. From the published
AAR: its Java classes (`classes.jar`), its manifest and its metadata files
(`R.txt`, `proguard.txt`, `aar-metadata.properties`). From the ONNX Runtime
project: the ONNX Runtime library, the same file the published AAR carries,
for the two ABIs the application ships (arm64-v8a, armeabi-v7a). The x86 and
x86_64 libraries of the published AAR and its C and C++ API libraries are left
out; the application does not use them. The resulting AAR is not part of this
repository.

The components linked into that library, and ONNX Runtime, which ships beside
it, are listed with their license texts in `THIRD-PARTY-NOTICES.md`.

## SenseVoice (local model weights)

<https://github.com/FunAudioLLM/SenseVoice> — SenseVoiceSmall by FunAudioLLM /
Alibaba Group.

The weights are not distributed with this app. They are downloaded when the
user asks for the on-device model, from a fixed revision on Hugging Face, and
verified by SHA-256 before being installed; a mismatch aborts the install.

The weights are not covered by the MIT license that covers the SenseVoice
source code. They are covered by the FunASR Model Open Source License Agreement
(<https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE>), whose Section
2.2 requires attributing the source and author and retaining the model name.
The model is presented in the app as "SenseVoice".

The artifact used is the ONNX conversion published by the sherpa-onnx
maintainer: `csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`.

## Feedback sounds

The recording start and stop sounds (`rec_start.wav`, `rec_stop.wav`) are our own synthesis. They are generated by a
script rather than recorded or sampled, so they contain no third-party material
and are not derived from the upstream project.
